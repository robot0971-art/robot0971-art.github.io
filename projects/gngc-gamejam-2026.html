프로젝트 소개

GNGC Gamejam 2026은 AI를 주제로 한 2박3일 GNGC 게임잼에서 만든 게임입니다. 플레이어는 웨이브마다 등장하는 5명의 참가자를 관찰한 뒤 AI만 골라 제한된 탄 수 안에서 제거해야 합니다.

AI라는 주제를 단순한 소재가 아니라 "구분하고 판정하는 플레이"로 연결하는 데 초점을 맞췄습니다.

담당 역할

Game Loop
Stage Flow
Wave Generation
Shooting
HUD / UI
Camera Direction
Reward Event
Cutscene Integration

주요 기능

  • 웨이브마다 인간과 AI 참가자를 섞어 5명 단위로 생성
  • 저격 모드 전 참가자를 한 명씩 보여주는 프리뷰 흐름
  • AI 수와 같은 탄 수를 지급하고, 오발과 잔여 AI 여부로 결과 판정
  • 하트, 탄 수, 타이머, 클리어/게임 오버 패널을 HUD로 표시
  • 스테이지별 AI 스프라이트 세트와 인간/AI 중복 번호 방지 규칙 적용
  • 마우스 입력과 2D Raycast 기반 사격, 조준 대상 자동 선택 처리
  • 스테이지 클리어 후 랜덤 보상 선택과 다음 스테이지 효과 적용
  • 실패한 스테이지에서 랜덤 프리뷰를 다시 구성하는 리스타트 처리

개발 포인트

Core는 스테이지 진행, 타이머, 결과 판정, 보상 적용을 담당하고 Gameplay는 참가자 데이터, 웨이브 생성, 사격 규칙을 담당하도록 나눴습니다.

같은 번호의 인간과 AI가 동시에 등장하지 않도록 웨이브 생성 규칙을 두어, 랜덤 구성 안에서도 플레이어가 공정하게 판단할 수 있게 했습니다.

Presentation 계층은 HUD, 카메라 연출, 컷신, UI를 담당하도록 분리해 게임잼 기간에도 기능 수정이 다른 시스템에 영향을 주지 않도록 구성했습니다.

배운 점

짧은 시간 안에 규칙이 명확한 게임을 만들려면, 처음부터 플레이어가 언제 관찰하고 언제 판단하는지 흐름을 분명히 잡는 것이 중요하다는 점을 배웠습니다.

또한 랜덤 웨이브 생성처럼 작은 규칙 하나가 게임의 공정함에 큰 영향을 주기 때문에, 데이터 구성과 판정 로직을 UI와 분리해 검증하기 쉬운 구조로 두는 것이 도움이 됐습니다.
